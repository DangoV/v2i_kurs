# V2I курсовая: приоритет трамвая на 8 перекрёстках

Эта программа адаптирована под вашу курсовую работу и её исходные допущения:
- 8 регулируемых перекрёстков;
- интервал движения трамвая по умолчанию 10 минут;
- моделирование 2 часа с дискретностью 1 секунда;
- V2I-ограничения: latency 20–100 мс, packet loss до 5%, радиус связи учтён через вероятность успешного приоритета;
- ограничение продления зелёной фазы до `+15` сек.

## Что рассчитывает
- среднюю задержку трамвая и `p95`;
- сокращение задержки относительно базового сценария;
- влияние на пропускную способность перекрёстков;
- среднюю скорость маршрута;
- число остановок на трамвай;
- долю успешных приоритетов;
- штраф по задержке авто-потока.

## Форматы данных
Генерируются и сохраняются:
- `intersections.csv/json`
- `tram_schedule.csv/json`
- `traffic.csv/json`
- `signal_log.csv/json`
- `v2i_log.csv/json`
- `tram_position.csv/json`
- `v2i_data.sqlite`

## Запуск
```bash
python -m v2i.main run --seed 42 --headway-sec 600
```

Отдельные команды:
```bash
python -m v2i.main generate --out-dir data_out --seed 42
python -m v2i.main simulate --in-dir data_out
python -m v2i.main optimize --in-dir data_out
python -m v2i.main sensitivity --in-dir data_out
python -m v2i.main train-ml --in-dir data_out
```

## Алгоритмы
- ETA: на основе расстояния и скорости.
- Логика приоритета: если ETA меньше порога и V2I-пакет не потерян — продление зелёной фазы (не больше 15 сек).
- Оптимизация: `scipy.differential_evolution` по целевой функции `J = α*D_tram + β*D_cars`.
- ML (вспомогательно): RandomForest для прогноза ETA; хронологическое разбиение 70/30.

## Соответствие разделам курсовой
- Подготовка данных: есть генерация `tram_position/traffic/signal_log/v2i_log`.
- Моделирование: baseline vs V2I + sensitivity-анализ.
- Метрики: задержки, скорость, остановки, throughput, устойчивость к packet loss.
