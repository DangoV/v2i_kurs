# Курсовой проект: V2I-мониторинг светофоров и приоритет трамвая

Проект реализует модель распределённой системы V2I для 8 перекрёстков, где трамвай получает адаптивный приоритет на светофорах. Решение покрывает:

- генерацию синтетических данных (карта, расписание трамваев, задержки светофоров по времени суток);
- хранение и экспорт/импорт в `CSV`, `JSON`, `SQLite`;
- имитационную оценку двух сценариев:
  - **baseline** (без приоритета),
  - **v2i_priority** (адаптивный приоритет трамвая);
- оптимизацию параметров приоритета с помощью `SciPy`;
- ML-оценку задержек на `scikit-learn` + опционально на `PyTorch`.

## Стек

- `pandas`, `numpy`
- `scikit-learn`
- `scipy`
- `torch` (опционально)

## Быстрый запуск

```bash
python -m v2i.main run --seed 42
```

Команда:

1. генерирует синтетические данные;
2. сохраняет их в `data_out/` (`CSV/JSON/SQLite`);
3. считает KPI для baseline и V2I;
4. оптимизирует параметры V2I;
5. обучает `RandomForestRegressor` для прогноза задержки;
6. (если установлен `torch`) обучает простой MLP-регрессор.

## Структура

- `v2i/generator.py` — генерация синтетических данных;
- `v2i/io_utils.py` — сохранение/загрузка данных;
- `v2i/simulation.py` — модель задержек и пропускной способности;
- `v2i/optimization.py` — поиск оптимальных параметров V2I;
- `v2i/ml_models.py` — ML-модели;
- `v2i/main.py` — CLI-оркестратор.

## Модель и показатели

Оптимизируемая функция учитывает:

- среднюю задержку трамвая (сек);
- изменение общей пропускной способности перекрёстков (%);
- штраф за чрезмерный приоритет (чтобы не блокировать авто-потоки).

Основные KPI:

- `tram_avg_delay_sec`
- `tram_p95_delay_sec`
- `intersection_throughput_veh_per_h`
- `throughput_change_pct`
- `priority_activations`

## Пример запуска отдельных команд

Генерация:

```bash
python -m v2i.main generate --out-dir data_out --seed 7
```

Симуляция:

```bash
python -m v2i.main simulate --in-dir data_out
```

Оптимизация:

```bash
python -m v2i.main optimize --in-dir data_out
```

ML:

```bash
python -m v2i.main train-ml --in-dir data_out
```
